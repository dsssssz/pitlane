Методика

Честно о том, как Pitlane измеряет время и что попадает в публичные топы. Без маркетинга.

Как работает GPS-замер и круг

Телефон получает координаты через браузерный GPS (Geolocation API). Pitlane не «рисует» скорость с сервера карт — только ваши точки и локальная fusion-логика (GPS + при доступности IMU/датчики движения).

  • 0–100 — сессия на прямой: старт по движению/вооружению, финиш по порогу скорости. Время считается по меткам GPS.
  • Круг — летящие круги на выбранной трассе. Старт/финиш только при пересечении линии С/Ф на GPS (авто-финиш). Ручной «финиш» сохраняет круг у вас, но не пускает в топ.

Точность зависит от телефона, неба, помех и частоты точек. Плохой GPS ≠ «вы медленные» — это просто слабый сигнал.

Оценки GPS: A / B / C

A · Честный хорошая средняя точность, мало плохих точек, без телепортов и явных speed-флагов.

B · Ок приемлемо для топа: сигнал не идеальный, но без грубых аномалий.

C · Слабый GPS слабая точность, много мусора или подозрительные скачки — результат можно сохранить и шарить, в публичный топ не идёт.

В интерфейсе бейдж всегда виден. Нажмите на него — увидите среднюю точность (±м) и частоту точек (Гц), если они есть в данных.

Что никогда не попадает в публичные топы

  • Ручной финиш круга (нужен авто-финиш на линии С/Ф)
  • Оценка C (слабый GPS)
  • Флаги телепорта / нереальной скорости
  • Явно невалидные сессии (мало дистанции, «пауза», слишком быстро для длины трассы и т.п.)

Серверная перепроверка

Клиент уже отсекает слабые результаты. Worker API дополнительно пересчитывает valid: публичный топ — только GPS A/B без teleport/speed. Подделать «валид» в теле запроса недостаточно.

Погода: сухо / сыро / мокро

Для кольца при сохранении круга пишется категория погоды (Open-Meteo weather_code у трассы):

  • Сухо — ясно / облачно / туман без осадков
  • Сыро — морось, слабый дождь
  • Мокро — умеренный+ дождь, ливни, гроза, снег

Погода — ориентир условий, не лабораторный датчик покрытия. Сравнивайте круги в одном бакете. В топах кольца фильтр по умолчанию — Сухо (если такие записи есть), иначе «Все».

Шейр-карточка

Карточка показывает время, машину, оценку GPS, погоду (если есть) и ссылку. Оценка C помечается как «не в топ». Ссылка ?s= / офлайн #r= открывает ту же карточку.

Дуэли

Личный вызов другу: 0–100 или круг на выбранной трассе. В дуэль принимаются только заезды GPS A/B (как в публичных топах). Победитель — меньшее время; при равенстве — ничья. Ссылка ?duel= / #duel=.

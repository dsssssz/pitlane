# PITLANE GPS — свой «Dragy»: внешний GNSS 10–25 Гц по Bluetooth

Приёмник u-blox (NEO-M9N или MAX-M10S) + ESP32-C3/ESP32-S3. ESP32 настраивает приёмник по UBX
(только NAV-PVT, без NMEA, 10 Гц, модель «automotive», 115200 бод), разбирает NAV-PVT и шлёт в телефон
компактный 20-байтный пакет по BLE. Приложение Pitlane («Замер» → «Источник GPS» → «Внешний GPS (PITLANE GPS)»)
подключается через Web Bluetooth и подаёт точки в тот же пайплайн замеров/кругов вместо GPS телефона.

> Web Bluetooth есть только в **Chrome на Android** (и Chrome/Edge на компьютере).
> На iPhone и внутри Telegram его нет — приложение покажет понятное сообщение.

## 2. Подключение

Схема: [`docs/pitlane-gps-wiring.svg`](docs/pitlane-gps-wiring.svg) / [`.png`](docs/pitlane-gps-wiring.png)

| Откуда | Куда (ESP32-C3 SuperMini) | ESP32-S3 | Комментарий |
|---|---|---|---|
| GPS **VCC** | **3V3** | 3V3 | плата M9N/M10 на 3,3 В (для Matek — 5V, см. выше) |
| GPS **GND** | **GND** | GND | |
| GPS **TX** | **GPIO20** (RX) | GPIO18 | данные NAV-PVT → ESP32 |
| GPS **RX** | **GPIO21** (TX) | GPIO17 | команды UBX ← ESP32 |
| GPS PPS | — | — | не нужен |
| LiPo **+** / **−** | TP4056 **B+** / **B−** | | |
| TP4056 **OUT+** | через выключатель → **5V** | 5V | стабилизатор платы ESP32 делает 3,3 В |
| TP4056 **OUT−** | **GND** | GND | |
| делитель 100k/100k: верх — OUT+, низ — GND, середина → | **GPIO3** (ADC) | GPIO1 | опционально: заряд батареи в приложении |
| кнопка | встроенная **BOOT = GPIO9** | GPIO0 | короткое нажатие: 10 ↔ 25 Гц |
| светодиод | встроенный **GPIO8** | — | часто мигает — нет данных от GPS; 1 Гц — нет фикса; вспышка раз в 2 с — фикс, телефон не подключён; горит — фикс + телефон |

⚠️ Когда прошиваете по USB-C самой ESP32 — **выключите выключатель батареи** (на 5V не должны одновременно
сидеть USB и LiPo). Заряжать батарею — через USB-C платы TP4056.

## 3. Прошивка

### Вариант А: через браузер (без установки программ)
1. Chrome/Edge **на компьютере** → `https://dsssssz.github.io/pitlane/hardware/pitlane-gps/web-flash/`
2. Подключите ESP32 кабелем USB-C → «Прошить PITLANE GPS» → выберите порт.
3. Если порт не виден: зажмите BOOT, переподключите USB, отпустите BOOT.

Готовые образы лежат в `web-flash/` (`pitlane-gps-esp32c3.bin`, `pitlane-gps-esp32s3.bin`, пишутся с адреса 0x0).

### Вариант Б: PlatformIO
```bash
pip install platformio
cd hardware/pitlane-gps
pio run -e esp32c3 -t upload      # или -e esp32s3
pio device monitor                # лог 1 раз в секунду
./build-web.sh                    # пересобрать образы для браузерной прошивки
```

## 4. Как проверить

1. **Без телефона:** `pio device monitor`. Сразу после старта должно быть
   `GNSS NEO-M9N-00B: UBX OK, rate 10 Hz`, дальше раз в секунду:
   `fix=3 ok=1 sv=18 ... | 10 Hz | bat 3950 mV 70% | BLE off`.
   `НЕ ОТВЕЧАЕТ` — перепутаны TX/RX или нет питания GPS.
2. **С телефоном (Android + Chrome):** откройте Pitlane → «Замер» → «Внешний GPS (PITLANE GPS)» →
   выберите `PITLANE-GPS-XXXX`. Под скоростью появится строка: `PITLANE-GPS-… · 10.0 Гц · 18 спутн. · ±0.9 м · ±0.12 м/с · 🔋 70%`.
   Зелёная — всё хорошо (3D-фикс, ≥8 спутников, точность ≤2,5 м, ≥8 Гц).
3. **Без железа:** кнопка «Симулятор» в том же блоке — 4 с стоим, затем разгон ~0–100 за 4,2 с до 230 км/ч.
4. Тест протокола: `node hardware/pitlane-gps/test/protocol.test.mjs`.

Первый холодный старт приёмника под открытым небом — до ~30 с до фикса; в машине антенну лучше на крышу/под лобовое.

## 5. BLE-протокол

Сервис `21d60001-18f2-4d0c-aa95-1402d5296fdd`, подробности — `src/protocol.h`.

| Характеристика | UUID | Свойства | Содержимое |
|---|---|---|---|
| PVT | `21d60002-…` | notify | 20 байт на каждую эпоху (10/25 Гц): seq, fixType+gnssFixOK, numSV, hAcc (0,1 м), iTOW (мс), lat/lon (1e-7°), gSpeed (см/с, доплер), sAcc (см/с), курс (360/256°) |
| Статус | `21d60003-…` | read, notify 1 Гц | 8 байт: версия, частота, батарея мВ и %, флаги (настроен / идут PVT / 25 Гц / M10), факт. PVT/с |
| Управление | `21d60004-…` | write | 1 байт = частота: 1, 5, 10 или 25 |

Пакет специально 20 байт — влезает в минимальный MTU, дробить не нужно. Время точек в приложении считается по
iTOW приёмника (точные интервалы, без задержек Bluetooth); скорость — доплеровская `gSpeed` напрямую, а старт
0–100 определяется с момента трогания (1 км/ч).

## 6. Что проверено и что нет

- ✅ Прошивка компилируется (PlatformIO, espressif32 6.9.0, NimBLE-Arduino 2.x) для ESP32-C3 и ESP32-S3.
- ✅ Разбор пакета и симулятор — тест `test/protocol.test.mjs`; приложение в headless Chrome: симулятор → «Старт» → 0–100 записывается.
- ❌ На реальном железе **не проверялось**: ответы u-blox на CFG-VALSET, реальные 25 Гц, стабильность BLE на 25 Гц,
  измерение батареи, Web Bluetooth на конкретном телефоне.

PITLANE GPS — прошивка через браузер

  1. Откройте эту страницу в Chrome или Edge на компьютере (нужен Web Serial).
  2. Подключите плату ESP32-C3/ESP32-S3 кабелем USB-C (кабель с данными, не только зарядный).
  3. Нажмите кнопку ниже, выберите порт (обычно «USB JTAG/serial debug unit»), подтвердите.

Комплект «USB от машины» (корпус C, один световод)

Этот браузер не поддерживает Web Serial — нужен Chrome/Edge на компьютере. Нужна страница по HTTPS.

Без аккумулятора, один статусный LED, 25 Гц. Настройка Wi-Fi повторно — выдернуть и вставить USB 3 раза подряд.

Версия с аккумулятором и подсветкой (корпус B) / ESP32-S3

Этот браузер не поддерживает Web Serial — нужен Chrome/Edge на компьютере. Нужна страница по HTTPS.

Прошивка 2.1.0 (Wi-Fi): при первой прошивке отметьте «стереть устройство» — изменилась таблица разделов. После перезапуска чип сам включит сеть PITLANE-GPS-XXXX (пароль pitlanegps) для настройки хотспота и привязки к аккаунту — с iPhone тоже. Пошагово — в README чипа, раздел «Wi-Fi и iPhone».

Прошить с iPhone нельзя (в iOS нет Web Serial) — нужен один раз компьютер; дальше всё настраивается с телефона.

Если порт не появляется: зажмите кнопку BOOT, нажмите RESET (или переподключите USB), отпустите BOOT — и повторите.

Исходники: hardware/pitlane-gps/ в репозитории pitlane.

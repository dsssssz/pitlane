      Как подключить с iPhone
      1. Здесь нажмите «Привязать чип» — появится код.
      2. Чип: первый запуск — сам включает сеть настройки; иначе удерживайте кнопку BOOT 3 с (индикатор связи — фиолетовый).
      3. iPhone: Настройки → Wi-Fi → «PITLANE-GPS-XXXX», пароль pitlanegps. Откроется страница настройки (если нет — Safari, адрес 192.168.4.1).
      4. Впишите имя iPhone (Настройки → Основные → Об этом устройстве → Имя), пароль режима модема и код. «Сохранить».
      5. Выйдите из сети PITLANE-GPS. Настройки → Режим модема → включите «Разрешать другим» и «Максимальная совместимость» (2.4 ГГц). Не закрывайте этот экран, пока чип не подключится.
      6. Индикатор связи на чипе горит голубым — поток идёт. Здесь появится «чип в сети».
      7. Едем: стоите — замер сам вооружается, трогаетесь — отметки всплывают, начали сбавлять — итог.

      Внешний приёмник u-blox 10–25 Гц: по Bluetooth — Android + Chrome; по Wi-Fi (режим модема телефона) — iPhone и Telegram. Топ разгонов (0–100, 100–200, 80–120, ¼ мили) принимает только его; телефон и симулятор — в личную историю. Время на экране — справочно, в топ — после проверки сервером по сырым точкам.

# Студийные превью машин (v123)

Рендер тех же GLB, что в Боксе (та же нормализация: длина 4,8 м, `rotation.y = 0.2π`, номера PITLANE из `plates.js`).
Свет: своё окружение PMREM (верхний софтбокс, длинные стрипы, контровые панели, тонкий неоновый стрип только для отблеска),
ключевой свет с мягкой тенью, два контровых, ACES; глянцевый графитовый пол, уходящий в фон, контактная тень, мягкое отражение.
Камера 3/4 спереди, низко, FOV 24°.

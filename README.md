# Pitlane

MVP гаража для энтузиастов скорости: 3D-бокс, паспорт разгона, круги.

Открыть `index.html` через локальный сервер (модули Three.js не работают как `file://`).

```bash
cd pitlane
python3 -m http.server 5174
```

Затем http://localhost:5174

- Главная: крутить модель, капот / двери / багажник
- Динамика: 0–100, 100–200, 200–300 + свой замер (localStorage)
- Круг: эталон трассы и свои сессии
- Парк: M3, 911 GT3, GT-R Nismo, Huracán STO

Замеры с телефона и настоящие GLB-кузова — следующий этап.
